# GeoTrazo

Programa de geometría de precisión para Windows 10/11 de 64 bits.

## Descargar

Abre [la publicación más reciente](https://github.com/fran56caton/geotrazo-actualizaciones/releases/latest) y descarga **GeoTrazo-Instalar-…-Windows-x64.exe**. Incluye WebView2 para instalar sin conexión. La biblioteca de un usuario nuevo empieza vacía; puedes personalizar el nombre en el rotulado y los campos de la carátula.

## Actualizaciones

Desde la copia 0.8.1, GeoTrazo comprueba las mejoras al abrir, al volver internet y cada cuatro horas. Descarga el paquete reducido, verifica su firma y ofrece **Guardar y reiniciar para actualizar**. El botón **Buscar actualizaciones** también permite comprobar manualmente. Las copias anteriores necesitan instalar esta copia una vez.

El paquete **GeoTrazo-Actualizar-…** lo utiliza el actualizador de una instalación existente. Para instalar en un equipo nuevo utiliza el paquete **GeoTrazo-Instalar-…**.

## Tus archivos

Cada equipo guarda sus propios dibujos y PDF. Este repositorio contiene instaladores, firmas y documentación; no contiene bibliotecas personales. Dibujar, guardar, abrir PDF importados y exportar funcionan sin internet. Las actualizaciones conservan los trabajos del usuario. Haz copias periódicas con las opciones de copia de seguridad de Mis trabajos.

El producto mantiene la identificación visible GeoTrazo 0.8. Los números 0.8.x permiten comprobar si hay mejoras del instalador. Editar el código no es una publicación: las mejoras se compilan, firman, comprueban y publican antes de ofrecerse a los usuarios.
